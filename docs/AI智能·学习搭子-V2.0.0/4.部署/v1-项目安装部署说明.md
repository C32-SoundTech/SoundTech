### V2.0.0 安装部署手册
---
* 此文档仅对项目的进阶部署形式进行部分说明，基础部署请参考《构建过程手册》（docs/AI智能·学习搭子-V2.0.0/3.构建/构建过程手册.md）。
---
* HTTPS 部署（开发默认启用）：应用默认以 `https://` 方式启动（端口 `443`），证书/私钥路径为 `static/localhost.crt`、`static/localhost.key`；如需自定义端口或证书路径，使用 `--port`、`--cert`、`--key` 参数；证书可通过 Let's Encrypt、OpenSSL 或云服务商证书服务获取。
---
* 公网部署：可直接在云服务器部署或使用 FRP 等内网穿透服务实现公网访问。

本手册提供本地开发部署与生产（容器）部署方式，在 V1.0.0 基础上进行开发并支持新增接口与模块。

#### 1. 部署目标
- 在开发环境以 HTTPS（自签证书）或 HTTP 启动应用，验证页面与接口。
- 在生产环境以容器或 `waitress` 方式稳定运行，支持观察与日志。

#### 2. 前置准备
- 获取运行包（`min/full` 任选其一）。
- 准备 Python 虚拟环境（参考《构建过程手册》）。
- 配置文件：`config/config.toml`、`config/custom_key.toml`、`config/log_config.toml`。
- 开发 HTTPS（默认启用）：`static/localhost.crt`、`static/localhost.key`（注：应用默认以 HTTPS 方式启动，需确保证书/密钥文件存在）。

#### 3. 本地开发部署
1. 启动（HTTPS）

```powershell
python app.py
```
默认端口为 `443` 并启用开发证书；可通过参数覆盖端口（示例：`python app.py --host 0.0.0.0 --port 5000 --cert ./static/localhost.crt --key ./static/localhost.key`），仍为 HTTPS。

2. 启动（开发 HTTPS 配置说明）

- 应用默认启用 HTTPS；请确保 `static/localhost.crt` 与 `static/localhost.key` 存在且为开发证书。
- 如需自定义端口或证书路径，使用 `--port`、`--cert`、`--key` 参数。

```powershell
python app.py --host 127.0.0.1 --port 5000 --cert ./static/localhost.crt --key ./static/localhost.key
```

3. 生产近似（waitress）

```powershell
pip install waitress
waitress-serve --host 0.0.0.0 --port 8000 app:app
```

#### 4. 容器部署
1. 拉取镜像

```powershell
docker pull bytebrewer777/soundtech:v2
```

2. 运行容器

```powershell
docker run -d --name soundtech-v2 -p 5000:5000 soundtech-v2
```
- 如需加载自定义配置或数据，可使用 `-v` 映射：
```powershell
docker run -d --name soundtech-v2 -p 5000:5000 \
  -v "$PWD/config:/app/config" \
  -v "$PWD/resources:/app/resources" \
  soundtech-v2
```

  3. 查看容器状态，确认部署成功。
  ```powershell
  docker ps
  docker logs soundtech-v2
  ```

#### 5. 验证步骤
- 开发启动访问：`https://localhost:443/`；容器启动访问：`https://localhost:5000/`。
- 页面与路由：`/`、`/browse`、`/login`、`/register`、`/statistics`、`/exam`、`/timed_mode`。
- 接口（V2 新增）：`POST /api/qa/ask`、`GET /api/rag/sources`、`POST /api/feedback`、`GET /api/analytics/user`、`POST /api/workflows/run`。
- 日志与错误：查看日志输出是否按 `config/log_config.toml` 生效；错误码与返回体统一 `code/message/data`。

#### 6. 常见问题与处理
- 自签证书：开发自签名证书仅用于本地；生产使用正式证书或由反向代理（Nginx/Traefik）终止 TLS。
- 端口占用：`443/5000/8000` 被占用时，使用 `--port` 参数调整。
- 向量索引不存在：使用 `handlers/vector_db_init.py` 重建，或使用包含索引的运行包。
- 依赖冲突：清理虚拟环境并重新安装依赖或使用离线 wheels。
