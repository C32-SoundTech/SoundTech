### V2.0.0 安装部署手册

本手册提供本地开发部署与生产（容器）部署方式，在 V1.0.0 基础上进行开发并支持新增接口与模块。

#### 1. 部署目标
- 在开发环境以 HTTPS（自签证书）或 HTTP 启动应用，验证页面与接口。
- 在生产环境以容器或 `waitress` 方式稳定运行，支持观察与日志。

#### 2. 前置准备
- 获取运行包（`min/full` 任选其一）。
- 准备 Python 虚拟环境（参考《构建过程手册》）。
- 配置文件：`config/config.toml`、`config/custom_key.toml`、`config/log_config.toml`。
- 开发 HTTPS（可选）：`static/localhost.crt`、`static/localhost.key`。

#### 3. 本地开发部署
1. 启动（HTTP）

```powershell
cd "d:/Software Documents/JetBrains/PyCharm Professional 2025/SoundTech/SoundTech_1"
".\.venv\Scripts\Activate.ps1"
python app.py
```
默认端口（如 `5000`）由 `app.py` 中配置或 `config/config.toml` 控制。

2. 启动（开发 HTTPS）

- 请确保 `static/localhost.crt` 与 `static/localhost.key` 存在且为开发证书。
- 按需在 `app.py` 或启动脚本中指定证书路径（如已有封装）。

3. 生产近似（waitress）

```powershell
pip install waitress
waitress-serve --host 0.0.0.0 --port 8000 app:app
```

#### 4. 容器部署
1. 拉取镜像

```powershell
docker pull bytebrewer777/soundtech:v2
```

2. 运行容器

```powershell
docker run -d --name soundtech-v2 -p 5000:5000 bytebrewer777/soundtech:v2
```
- 如需加载自定义配置或数据，可使用 `-v` 映射：
```powershell
docker run -d --name soundtech-v2 -p 5000:5000 \
  -v "$PWD/config:/app/config" \
  -v "$PWD/resources:/app/resources" \
  bytebrewer777/soundtech:v2
```

  3. 查看容器状态，确认部署成功。
  ```powershell
  docker ps
  docker logs soundtech
  ```

#### 5. 验证步骤
- 页面与路由：`/`、`/browse`、`/login`、`/register`、`/statistics`、`/exam`、`/timed_mode`。
- 接口（V2 新增）：`POST /api/qa/ask`、`GET /api/rag/sources`、`POST /api/feedback`、`GET /api/analytics/user`、`POST /api/workflows/run`。
- 日志与错误：查看日志输出是否按 `log_config.toml` 生效；错误码与返回体统一 `code/message/data`。

#### 6. 常见问题与处理
- 证书错误：开发证书仅用于本地；生产请使用正式证书或反向代理（如 Nginx/Traefik）。
- 向量索引不存在：使用 `handlers/vector_db_init.py` 重建，或改用含索引包。
- 依赖冲突：清理虚拟环境，重新安装或使用离线 wheels。
