# v1-项目源代码

- 项目下载链接：`https://github.com/C32-SoundTech/SoundTech/blob/main/docs/AI智能·学习搭子-V2.0.0/2.代码/AI智能·学习搭子-V2.0.0.zip`
- 项目根目录：`SoundTech/`

**目录结构总览**
- `agentUniverse/` 框架与核心代码
- `docs/` 文档与交付物（V1/V2各阶段）
- `examples/` 示例工程与脚手架
- `resources/` 项目资源（教材、数据等）
- `README.md` 项目说明
- 其他：`Dockerfile`、`.gitignore`、`LICENSE` 等

**源代码目录：agentUniverse/agentuniverse/**
- `agent/` 智能体能力域
  - `action/knowledge/` RAG知识能力
    - `knowledge.py` 知识管线主类（构建与查询）
    - `reader/` 数据读取（PDF/网页/云端等）
    - `doc_processor/` 文档处理（分块/关键词/重排）
    - `store/` 存储与检索（Chroma/Milvus/SQLite/Neo4j）
    - `rag_router/` RAG路由（全量/语义选路）
    - `query_paraphraser/` 查询改写（关键词抽取等）
  - `default/` 内置智能体实现（RAG/Peer/Planning等）
  - `memory/` 记忆系统（对话记忆、存储、管理）
  - `plan/` 计划系统（Planner与管理）
  - `template/` 智能体模板（RAG/React等）
  - `work_pattern/` 工作模式
  - 根：`agent.py`、`agent_manager.py`、`agent_model.py`、`input_object.py`、`output_object.py`
- `agent_serve/` 服务化与Web接口
  - `web/` HTTP/WS服务、RPC、任务分发
  - 根：`service.py`、`service_manager.py`、`service_instance.py`、`service_configer.py`
- `base/` 框架基础设施
  - `annotation/` 注解（重试/单例/trace）
  - `component/` 组件基类与枚举
  - `config/` 配置加载与类型枚举
  - `context/` 框架上下文与会话管理
  - `tracing/` 观测与遥测（otel）
  - `util/` 工具库（日志、监控、提示词、系统等）
  - 根：`agentuniverse.py`
- `database/` 通用数据库封装（SQL）
- `llm/` 模型接入层
  - `default/` 常用模型适配与配置（OpenAI、Wenxin、Qwen、Kimi、Claude等）
  - `llm_channel/` 模型通道（Ollama、Qianfan等）
  - 根：`llm.py`、`llm_manager.py`、`langchain_instance.py` 等
- `prompt/` 提示词系统
- `workflow/` 工作流编排（节点/图/执行）

**主要代码目录：知识与RAG相关（关键）**
- `agentUniverse/agentuniverse/agent/action/knowledge/knowledge.py`
  - 构建索引：`insert_knowledge(...)`
  - 更新索引：`update_knowledge(...)`
  - 查询管线：`query_knowledge(...)`
  - 读取数据：`_load_data(...)` 自动选择 Reader
  - 文档处理：`_insert_process(...)` / `_rag_post_process(...)`
  - 查询改写：`_paraphrase_query(...)`
  - 路由与并发：`_route_rag(...)` 并发提交到 Store
- `reader/`：PDF、DOCX、PPTX、CSV、Markdown、代码、网页、飞书/语雀等Reader
- `doc_processor/`：
  - `recursive_character_text_splitter.py` 递归分块
  - `jieba_keyword_extractor.py` 关键词抽取
  - `dashscope_reranker.py`、`jina_reranker.py` 检索重排
- `store/`：
  - `chroma_store.py` 向量检索（本地/远程）
  - `milvus_store.py` 向量检索（集合/索引/HNSW）
  - `sqlite_store.py` 倒排索引与BM25
  - `document.py`、`query.py` RAG领域对象
- `rag_router/`：
  - `base_router.py` 全量并发
  - `nlu_rag_router.py` 语义选路（Agent决策）
- `query_paraphraser/`：
  - `query_keyword_extractor.py` 查询关键词改写
