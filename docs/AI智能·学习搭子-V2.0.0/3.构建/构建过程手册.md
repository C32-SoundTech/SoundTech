### 构建过程手册
---
* Python语言的$【构建】$和$【部署】$实质上是一体的，因为Python是一种运行时的解释型语言，它的代码在运行时才会被解释执行，而不是像Java语言或C语言一样先被编译成二进制文件，故不存在明确的、业内公认的【构建结果文件】。
* 本文件夹下的`deploy.ps1`是针对**已经下载项目源码**的、但**系统中不具备Python运行环境**的powershell构建文件；
* 若**未下载项目源码**、且**系统中不具备Python运行环境**的，可移步至$【4.部署】$文件夹并执行其中的一键部署脚本`one-click-to-install.ps1`，即可进行一键部署；
* 本文件夹下的`构建结果文件.zip`实质上是一个包含嵌入式Python解释器和项目源码的文件夹；
* 若使用本项目构建脚本所搭建的嵌入式Python运行环境，请在运行时切换到对应文件夹下，使用`.\python-3.11.9-embed-amd64\python.exe .\app.py`运行系统。
---
* **注意：**若你的系统中已有相关Python运行环境，相信你也知道一些Python的基本用法；
* 你可以遵循以下步骤，来运行这个项目：
```powershell
# 创建虚拟环境
python -m venv SoundTech
# 激活虚拟环境
.\SoundTech\Scripts\Activate
# 安装项目依赖
pip install -r requirements.txt
# 运行项目
python .\app.py
```
---
* 以下是针对$【4.部署】$文件夹中一键部署脚本`one-click-to-install.ps1`的说明：
```powershell
Clear-Host
Write-Host "Downloading SoundTech V2.0.0 Windows version..."
curl https://gitee.com/dingdust/SoundTech-Release/raw/main/V2.0.0-Windows.zip -o .\one-click-to-install.zip
New-Item -Path .\SoundTech -ItemType Directory
Expand-Archive -Path .\one-click-to-install.zip -DestinationPath .\SoundTech
Remove-Item -Path .\one-click-to-install.zip
Set-Location .\SoundTech

Clear-Host
Write-Host "Downloading Python 3.11.9 64-bit embedded version..."
curl https://gitee.com/dingdust/SoundTech-Release/raw/main/python-3.11.9-embed-amd64.zip -o .\python311-embed.zip

Clear-Host
Write-Host "Setting up Python 3.11.9 64-bit embedded version..."
New-Item -Path .\python311-embed -ItemType Directory
Expand-Archive -Path .\python314-embed.zip -DestinationPath .\python311-embed
Remove-Item -Path .\python314-embed.zip
Set-Location .\python311-embed
curl https://gitee.com/dingdust/SoundTech-Release/raw/main/python314.zip -o .\python311.zip 

Clear-Host
Write-Host "Downloading necessary requirements..."
curl https://gitee.com/dingdust/SoundTech-Release/raw/main/get-pip.py -o .\get-pip.py 
.\python.exe .\get-pip.py --no-warn-script-location
.\python.exe -m pip install -r ..\requirements.txt --index-url https://mirrors.aliyun.com/pypi/simple/ --no-warn-script-location
Set-Location ..

Clear-Host
.\python314-embed\python.exe .\app.py
```
* 该脚本执行了以下操作：
    * 下载SoundTech V2.0.0 Windows版本的源码压缩包并解压到当前文件夹；
    * 下载Python 3.11.9 64位嵌入式版本的压缩包并解压到当前文件夹（因文件大小超过10MB，故将运行时依赖`python311.zip`进行了分离）；
    * 下载并安装必要的Python依赖库；
    * 运行SoundTech V2.0.0 Windows版本。
    * 注意：若你的系统中已有相关Python运行环境，建议直接使用该环境运行项目，而不是使用本项目构建脚本所搭建的嵌入式Python运行环境。

* 构建脚本的搭建说明
1. 声像科技®团队将项目的源码进行最小化依赖分离，封装为`V2.0.0-Windows.zip`;
2. 下载了Python 3.11.9 64位嵌入式版本的压缩包，并更改了相应的配置信息，以适用于本项目的本地运行环境；具体为：
    * 更改了`python311._pth`的配置信息，添加本地运行时依赖：
    ```
    python311.zip
    .
    ..
    import site
    ```
    * 分离了压缩包中的`python311.zip`，将项目重新压缩为`python-3.11.9-embed-amd64.zip`（7.03MB）与`python311.zip`（3.89MB），使单文件体积<10MB，方便下载与部署；
3. 下载了Python中pip包管理器`get-pip.py`并进行安装，同时使用了[阿里云PYPI镜像源](https://mirrors.aliyun.com/pypi/simple/)来安装其他项目依赖；
4. 声像科技®团队提供了经以上方法部署项目的运行脚本命令`.\python-3.11.9-embed-amd64\python.exe .\app.py`，并执行。
