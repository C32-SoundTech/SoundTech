### 构建过程手册
---
* Python语言的$【构建】$和$【部署】$实质上是一体的，因为Python是一种运行时的解释型语言，它的代码在运行时才会被解释执行，而不是像Java语言或C语言一样先被编译成二进制文件，故不存在明确的、业内公认的【构建结果文件】。
* 本文件夹下的`构建结果文件.zip`实质上是一个包含嵌入式Python解释器和项目源码的文件夹；
* 若使用本项目构建脚本所搭建的嵌入式Python运行环境，请在运行时切换到对应文件夹下，使用`.\python-3.11.9-embed-amd64\python.exe .\app.py`运行系统。
---
* **注意：**若你的系统中已有相关Python运行环境，相信你也知道一些Python的基本用法；
* 你可以遵循以下步骤，来运行这个项目：
```powershell
# 创建虚拟环境
python -m venv SoundTech
# 激活虚拟环境
.\SoundTech\Scripts\Activate
# 安装项目依赖
pip install -r requirements.txt
# 运行项目
python .\app.py
```
