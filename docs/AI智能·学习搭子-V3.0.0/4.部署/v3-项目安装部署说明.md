# V3.0.0 安装部署手册

---

* 此文档仅对项目的进阶部署形式进行部分限定与说明。

---

* 声像科技®团队提供了项目的一键部署包（Windows），您可以直接通过`powershell`执行本文件夹下的`one-click-to-install.ps1`脚本进行部署。

---

* 声像科技®团队提供了项目的HTTPS部署形式，您可以通过配置SSL证书来实现。
  可通过以下方式实现SSL证书的申请：
  1. [Let's Encrypt](https://letsencrypt.org/)【免费】；
  2. [OpenSSL](https://www.openssl.org/)【免费】；
  3. 基于云服务器的域名+SSL证书服务【付费】；

---

* 声像科技®团队提供了项目的公网部署形式。
  可通过以下方式实现公网部署：
  1. 直接使用云服务器部署项目【免费/付费】；
  2. 使用[FRP](https://github.com/fatedier/frp)搭建本地-云服务器内网穿透服务【免费/付费】；
  3. 使用其他第三方公网部署服务【免费/付费】；

---

* 声像科技®团队提供了项目的Docker部署形式。

##### 1. 拉取镜像

```bash
docker pull bytebrewer777/soundtech:3.1.0
```

##### 2. 运行容器

```bash
docker run -d \
  --name soundtech-app \
  --restart unless-stopped \
  -p 443:443 \
  -e SECRET_KEY=your-random-secret-key-here \
  -e DASHSCOPE_API_KEY=your-dashscope-api-key \
  -e ANONYMIZED_TELEMETRY=False \
  bytebrewer777/soundtech:3.1.0
```

> **获取 DASHSCOPE_API_KEY**: 访问 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/) 创建 API Key（AI 答疑功能必需）


##### 3. 访问应用

浏览器打开: https://localhost:443 即可

##### 常用命令

```bash
# 查看状态
docker ps -f name=soundtech-app

# 查看日志
docker logs -f soundtech-app

# 停止服务
docker stop soundtech-app

# 启动服务
docker start soundtech-app

# 删除容器
docker rm -f soundtech-app

# 更新镜像
docker pull bytebrewer777/soundtech:3.1.0
docker rm -f soundtech-app
# 然后重新运行上面的 docker run 命令
```

##### 功能说明

- **答题系统**: 注册登录后可进行随机答题、顺序答题、模拟考试
- **AI 答疑**: 题目页面点击"AI答疑"获取智能解析（需配置 DASHSCOPE_API_KEY）
- **错题本**: 自动记录错题，支持针对性练习
- **收藏夹**: 收藏重点题目，添加标签
