### 安装部署手册
##### SoundTech® by Dingdust 2025.10.13
---
* 此文档仅对项目的进阶部署形式进行部分限定与说明，基础部署形式请参考[构建过程手册](../3.构建/构建过程手册.md)。
---
* 我们提供了项目的一键部署包（Windows），您可以直接通过`powershell`执行本文件夹下的`one-click-deploy.ps1`脚本进行部署。
---
* 我们提供了项目的HTTPS部署形式，您可以通过配置SSL证书来实现。
  可通过以下方式实现SSL证书的申请：
  1. [Let's Encrypt](https://letsencrypt.org/)【免费】；
  2. [OpenSSL](https://www.openssl.org/)【免费】；
  3. 基于云服务器的域名+SSL证书服务【付费】；
---
* 我们提供了项目的公网部署形式。
  可通过以下方式实现公网部署：
  1. 直接使用云服务器部署项目【免费/付费】；
  2. 使用[FRP](https://github.com/fatedier/frp)搭建本地-云服务器内网穿透服务【免费/付费】；
  3. 使用其他第三方公网部署服务【免费/付费】；
---
* 我们提供了项目的Docker部署形式。
  使用本项目提供的Docker Hub镜像进行容器化部署：
  1. 拉取Docker镜像；
  ```powershell
  docker pull bytebrewer777/soundtech:latest
  ```
  2. 运行容器；
  ```powershell
  docker run -d -p 443:443 --name soundtech bytebrewer777/soundtech:latest
  ```
  4. 查看容器状态，确认部署成功。
  ```powershell
  docker ps
  docker logs soundtech
  ``` 
---
* 本项目在运行测试时使用了OpenSSL生成的自签名证书，您可以根据需要替换为真实的SSL证书。
* 本项目在运行测试时使用了FRP搭建了公网部署服务，您可以根据需要配置本地-云服务器的内网穿透。
* 本项目在运行测试时使用了IP地址`124.223.89.143`与域名`zjgsu.icu`来进行测试，您可以根据需要替换为您自己的IP地址与域名。
