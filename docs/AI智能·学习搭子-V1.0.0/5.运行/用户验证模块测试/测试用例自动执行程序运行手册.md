# 测试用例自动执行程序运行手册

本文档说明如何在本地执行项目的浏览器自动化测试，生成并查看测试结果。内容包含环境准备、启动被测系统、执行脚本、查看结果以及常见问题处理。

## 1. 适用范围
- 操作系统：Windows 10/11
- Python：3.8 及以上
- 浏览器：Chrome（或 Edge/Firefox，需对应驱动）
- 项目路径：`e:\AI\code\SoundTech`

## 2. 环境准备
- 进入项目目录：
  - `cd e:\AI\code\SoundTech`
- 安装依赖：
  - `pip install -r requirements.txt`
- 检查 Python 版本：
  - `python -V`
- 检查浏览器安装及版本（用于匹配驱动）：
  - Chrome 版本查看：打开 Chrome → 右上角“更多”→“设置”→“关于 Chrome”

## 3. WebDriver 准备
自动化测试依赖浏览器驱动。默认脚本使用在线下载方式（`webdriver-manager`），需要联网。离线环境请使用本地驱动。

### 3.1 在线方式（默认）
- 直接运行测试脚本，驱动将自动下载。
- 若出现网络错误（如 `Could not reach host. Are you offline?`），改用离线方式。

### 3.2 离线方式（推荐在受限网络环境）
- 下载与本机浏览器版本匹配的驱动：
  - ChromeDriver：从官方或镜像下载对应版本的 `chromedriver.exe`。
- 放置路径（示例）：
  - `e:\AI\code\SoundTech\drivers\chromedriver.exe`
- 配置方法（二选一）：
  - 方式 A：将驱动目录加入系统 `PATH`。
  - 方式 B：在脚本中显式指定驱动路径（见 `test1/scripts/selenium_test.py` 的 `init_driver()`）。
- 驱动验证（可选）：
  - `python tests/verify_webdriver.py`
- Edge/Firefox：如使用其它浏览器，需下载对应驱动并调整脚本中的驱动类型。

> 详见驱动说明：`tests/WEBDRIVER_SETUP.md`

## 4. 启动被测系统（Web 服务）
- 在项目根目录启动应用：
  - `python app.py`
- 观察日志，确认服务启动成功：
  - 出现监听地址（示例）：`https://127.0.0.1:443/`
- 浏览器访问验证：
  - 打开 `https://127.0.0.1:443/`，确认站点可访问。
  - 首次访问 HTTPS 可能出现证书提示，选择继续访问。

## 5. 准备测试数据
- 测试用例 CSV 路径：
  - `e:\AI\code\SoundTech\test1\data\selenium_test_cases.csv`
- 如需修改或新增用例：
  - 使用文本编辑器按原列结构填写，保存为 UTF-8（建议无 BOM）。

## 6. 执行自动化测试
- 保持第一个终端正在运行 Web 服务（`python app.py`）。
- 在新的终端执行测试脚本：
  - `python test1\scripts\selenium_test.py`
- 脚本行为：
  - 自动逐条运行注册与登录用例。
  - 期间会打开/关闭浏览器窗口并进行页面交互。
  - 生成结果 CSV 与截图。

## 7. 查看测试结果
- 结果文件路径：
  - `e:\AI\code\SoundTech\test1\results\results_YYYYMMDD_HHMMSS.csv`
- 截图目录（按用例保存）：
  - `e:\AI\code\SoundTech\test1\results\screenshots\`
- CSV 字段说明（示例）：
  - `case_id`：用例编号
  - `module`：模块（注册/登录）
  - `expected_result`：期望结果
  - `actual_result`：实际识别结果
  - `test_status`：测试结论（通过/失败/未知结果）
  - `message`：补充说明或错误信息

## 8. 常见问题与处理
- 驱动下载失败（离线或网络受限）：
  - 报错：`requests.exceptions.ConnectionError: Could not reach host.`
  - 处理：使用离线驱动（见第 3.2 节），或配置代理后重试。
- 端口占用/启动失败：
  - 处理：关闭占用 443 端口的程序，或调整 `app.py` 的端口后重启。
- HTTPS 证书提示：
  - 首次访问选择继续或信任本地证书（证书位于 `static/localhost.crt`、`static/localhost.key`）。
- 页面结构变化导致“未知结果”：
  - 处理：在 `test1/scripts/selenium_test.py` 中调整元素选择器或关键字匹配规则（注册/登录的识别逻辑已集中在该文件）。
- 运行缓慢或超时：
  - 处理：减少用例数量；增大脚本中的等待时间（`WebDriverWait` 超时时间）。
- 截图未保存或 CSV 无法写入：
  - 处理：检查 `test1/results` 目录写权限；确保磁盘空间充足。

## 9. 命令汇总（可直接逐步执行）
- `cd e:\AI\code\SoundTech`
- `pip install -r requirements.txt`
- `python app.py`
- 另开终端：`python test1\scripts\selenium_test.py`
- 可选：验证驱动 `python tests\verify_webdriver.py`

## 10. 目录说明（与测试相关）
- `test1/data/selenium_test_cases.csv`：测试用例数据源
- `test1/scripts/selenium_test.py`：自动化测试脚本
- `test1/results/`：测试结果 CSV 与截图输出目录
- `templates/login.html`、`templates/register.html`：被测登录/注册页面模板
- `tests/`：额外的测试脚本与配置（含驱动说明）

## 11. 退出与清理
- 停止 Web 服务：切换到运行 `python app.py` 的终端，按 `Ctrl+C`。
- 关闭测试终端与浏览器窗口。
