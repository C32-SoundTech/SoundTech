## 1. 简介

本手册详细介绍了学习搭子应用的测试用例自动执行程序的使用方法。该程序用于自动化执行三种不同模式的测试：随机答题模式、顺序答题模式和定时答题模式，以验证应用的功能完整性和稳定性。

### 1.1 测试目标

- 验证随机答题模式的功能正确性
- 验证顺序答题模式的功能正确性
- 验证定时答题模式的功能正确性
- 生成详细的测试报告

### 1.2 适用范围

本测试程序适用于学习搭子应用的功能测试，包括但不限于：

- 开发环境中的功能验证
- 持续集成流程中的自动化测试
- 版本发布前的回归测试

## 2. 环境准备

### 2.1 系统要求

- 操作系统：Windows/Linux/macOS
- Python 版本：3.6 或更高
- 浏览器：Chrome（最新版本）

### 2.2 依赖安装

在运行测试前，请确保已安装所有必要的依赖：

```bash
# 安装 Selenium 和 WebDriver 管理器
pip install selenium webdriver-manager

# 安装项目依赖
pip install -r requirements.txt
```

### 2.3 环境配置

确保以下条件满足：

1. Chrome 浏览器已安装
2. 网络连接正常（用于下载 ChromeDriver）
3. 项目根目录已添加到 Python 路径

测试程序由以下文件组成：

- `run_tests.py`：测试执行主程序
- `testRandom.py`：随机答题模式测试用例
- `testSequential.py`：顺序答题模式测试用例
- `testTimedMode.py`：定时答题模式测试用例

## 4. 运行方法

### 4.1 基本运行

在命令行中，导航到测试文件所在目录，然后运行以下命令：

```bash
python run_tests.py
```

这将执行所有三种模式的测试用例，并在控制台输出测试结果。

### 4.2 运行特定模式测试

```bash
# 只运行随机答题模式测试
python run_tests.py --mode random

# 只运行顺序答题模式测试
python run_tests.py --mode sequential

# 只运行定时答题模式测试
python run_tests.py --mode timed
```

### 4.3 运行特定测试用例

```bash
# 运行特定的测试用例
python run_tests.py --test test_random_with_unanswered,test_all_questions_completed
```

### 4.4 生成测试报告

```bash
# 生成测试报告并保存到文件
python run_tests.py --report test_report.txt
```

## 5. 命令行参数

| 参数 | 说明 | 可选值 | 默认值 |
|------|------|--------|--------|
| `--mode` | 指定要运行的测试模式 | `all`, `random`, `sequential`, `timed` | `all` |
| `--test` | 指定要运行的测试用例名称，多个用逗号分隔 | 测试用例名称 | 无（运行所有测试） |
| `--report` | 指定测试报告输出文件路径 | 文件路径 | 无（输出到控制台） |
| `--verbosity` | 测试输出的详细程度 | `0`=安静, `1`=正常, `2`=详细 | `2` |

## 8. 常见问题与解决方案

### 8.1 ChromeDriver 相关问题

**问题**：无法自动下载或启动 ChromeDriver

**解决方案**：
- 确保网络连接正常
- 手动下载与 Chrome 版本匹配的 ChromeDriver
- 将 ChromeDriver 路径添加到环境变量

### 8.2 端口冲突

**问题**：测试启动失败，提示端口被占用

**解决方案**：
- 修改测试文件中的 `BASE_URL` 变量，使用不同的端口
- 关闭可能占用端口的其他应用程序
- 使用 `netstat -ano` 命令查找并终止占用端口的进程

### 8.3 测试超时

**问题**：测试执行时间过长或超时失败

**解决方案**：
- 增加 `WebDriverWait` 的超时时间
- 检查网络连接和服务器响应时间
- 在测试代码中添加更多的等待时间

### 8.4 数据库初始化问题

**问题**：测试失败，提示数据库错误

**解决方案**：
- 确保数据库配置正确
- 手动运行 `init_db()` 函数初始化数据库
- 检查数据库文件权限

### 9.2 测试依赖关系

- `testRandom.py` 依赖于 `app.py` 和 `handlers/database.py`
- `testSequential.py` 依赖于 `app.py` 和 `handlers/database.py`
- `testTimedMode.py` 依赖于 `app.py` 和 `handlers/database.py`
- 所有测试都依赖于 Selenium 和 Chrome 浏览器

### 9.3 注意事项

- 测试运行时会启动多个 Flask 服务器实例，确保没有其他程序占用指定的端口
- 测试使用无头模式运行 Chrome 浏览器，不会显示浏览器界面
- 测试完成后，所有启动的服务器和浏览器实例将自动关闭
- 测试数据库与生产数据库分离，不会影响实际应用数据
