# **一、用户认证模块测试用例说明**
## **（一）等价类划分法**
### **方法概述**
等价类划分是将输入域划分为若干个等价类，从每个等价类中选取少数代表性数据作为测试用例。

### **在注册功能中的设计思路**
**核心设计理念：**

1. 根据注册功能的业务规则，将每个输入字段的所有可能输入值划分为有效等价类和无效等价类
2. 有效等价类代表符合业务规则的输入，应该导致注册成功
3. 无效等价类代表违反业务规则的输入，应该导致注册失败并给出相应错误提示

**具体设计策略：**

1. **字符组成维度划分：**
    - 根据字段允许的字符类型
    - 设计包含合法字符的有效等价类和包含非法字符的无效等价类
    - 考虑边界字符的处理
2. **长度限制维度划分：**
    - 根据每个字段的长度要求
    - 设计符合长度要求的有效等价类和超出长度限制的无效等价类
    - 特别关注空值、最小长度、最大长度的处理
3. **格式要求维度划分：**
    - 针对有特定格式要求的字段
    - 设计符合格式的有效等价类和格式错误的无效等价类
    - 考虑格式的各个组成部分缺失或错误的情况
4. **业务规则维度划分：**
    - 根据唯一性要求（用户名不能重复）
    - 根据关联性要求（密码与确认密码必须一致）

**在本项目中的应用：**  
**用户名字段等价类划分：**

+ 有效等价类EC1：长度1-32位的合法字符串（字母、数字、中文、下划线、连字符）
+ 有效等价类EC2：包含特殊字符的用户名（如：用户_123-测试）
+ 无效等价类EC3：空字符串
+ 无效等价类EC4：超过32位的字符串
+ 无效等价类EC5：包含非法字符的字符串

**密码字段等价类划分：**

+ 有效等价类EC6：8位及以上包含大小写字母、数字、特殊字符的强密码
+ 有效等价类EC7：8位的最小长度密码
+ 无效等价类EC8：空密码
+ 无效等价类EC9：少于8位的短密码
+ 无效等价类EC10：只包含单一类型字符的弱密码

## **（二）边界值测试方法**
### **方法概述**
边界值分析是对等价类划分的补充，重点测试边界条件。

### **在注册功能中的设计思路**
**核心设计理念：**

+ 基于"错误更容易在边界条件下发生"的假设
+ 重点测试输入域边界上和边界附近的值
+ 通过测试边界值发现等价类划分可能遗漏的缺陷

**具体设计策略：**

1. **长度边界测试：**
    - 最小边界：测试字段允许的最小长度值
    - 最小边界-1：测试小于最小长度的值，验证拒绝逻辑
    - 最小边界+1：测试略大于最小长度的值，验证接受逻辑
    - 最大边界：测试字段允许的最大长度值
    - 最大边界+1：测试超过最大长度的值，验证拒绝逻辑
    - 最大边界-1：测试略小于最大长度的值，验证接受逻辑
2. **格式边界测试：**
    - 密码复杂度边界：测试刚好满足复杂度要求的最短密码组合

**在本项目中的应用：**  
**用户名长度边界值测试：**

+ 最小边界：1位字符（测试用例R07）
+ 最大边界：32位字符（测试用例R08）
+ 超出边界：0位（空字符串，测试用例R02）
+ 超出边界：33位及以上（虽未在当前用例中体现，但应考虑）

**密码长度边界值测试：**

+ 最小边界：8位字符（测试用例R06）
+ 超出边界：7位字符（测试用例R05）
+ 超出边界：0位（空密码，测试用例R03）

# **二、顺序答题模块测试用例说明**
## **（一）等价类划分法**
### **方法概述**
等价类划分是将输入域划分为若干个等价类，从每个等价类中选取少量具有代表性的数据作为测试用例，以减少测试数量同时保证覆盖主要功能路径。

### **在顺序答题功能中的设计思路**
**核心设计理念：**

1. 根据顺序答题功能的业务逻辑，将影响答题结果与流程的输入条件划分为**有效等价类**与**无效等价类**
2. **有效等价类**代表符合业务规则的操作流程，应正常进入下一题或完成提交
3. **无效等价类**代表违反业务规则的输入或操作，应导致系统拒绝执行并提示相应错误信息

**具体设计策略：**

1. **题目作答状态维度划分**
    - 区分"已作答""未作答""部分作答""重复作答"等情况
    - 设计对应的有效与无效等价类，验证系统是否按顺序限制作答
2. **题目顺序控制维度划分**
    - 顺序答题要求按题号顺序依次作答
    - 设计"按顺序作答"的有效等价类与"跳题作答"的无效等价类
3. **答题提交维度划分**
    - 设计"所有题已答且提交""部分题未答即提交""重复提交"等场景，验证系统提交逻辑正确性
4. **超时与中断维度划分**
    - 设计在答题超时、中途刷新、退出后重新进入的场景，验证状态恢复机制
5. **数据有效性维度划分**
    - 针对答题内容输入字段（如填空题答案、简答题内容等），划分"合法格式""非法字符""空值"等等价类

**在本项目中的应用：**  
**题目作答状态等价类划分：**

+ 有效等价类 EC1：按题号依次完成所有题目作答
+ 无效等价类 EC2：跳过题目直接提交
+ 无效等价类 EC3：重复作答同一题目
+ 无效等价类 EC4：清空已作答内容再提交

**答题顺序控制等价类划分：**

+ 有效等价类 EC5：依次点击"下一题"按钮作答
+ 无效等价类 EC6：直接访问未解锁题号的答题页面

**答题提交等价类划分：**

+ 有效等价类 EC7：全部题目作答完成后提交
+ 无效等价类 EC8：部分题未答时提交
+ 无效等价类 EC9：重复点击提交按钮

**时间与中断等价类划分：**

+ 有效等价类 EC10：规定时间内完成答题
+ 无效等价类 EC11：超时后提交
+ 无效等价类 EC12：中途刷新后数据未保存

## **（二）边界值测试方法**
### **方法概述**
边界值分析是对等价类划分的补充，主要测试输入或操作条件的边界，以发现临界状态下的潜在缺陷。

### **在顺序答题功能中的设计思路**
**核心设计理念：**  
基于"错误往往发生在边界条件附近"的原则，针对题目顺序、作答时限、输入长度等关键边界进行测试，确保系统在极端场景下依然稳定运行。

**具体设计策略：**

1. **题目序号边界测试**
    - 最小边界：第1题
    - 最大边界：最后一题
    - 超出边界：题号0或题号超出题目总数（非法访问）
2. **作答时间边界测试**
    - 最小边界：刚进入考试立即提交
    - 最大边界：倒计时结束时提交
    - 超出边界：时间到后仍尝试作答
3. **答案内容长度边界测试**
    - 针对填空题与简答题，测试最小输入长度（空）、最大允许字符数（如500字），以及超出长度的情况
4. **提交操作边界测试**
    - 测试单击提交与连续多次点击提交按钮，验证防重复提交逻辑

**在本项目中的应用：**  
**题目序号边界值测试：**

+ 最小边界：第1题（测试用例 Q01）
+ 最大边界：最后一题（测试用例 Q02）
+ 超出边界：题号为0或超出题目总数（测试用例 Q03）

**作答时间边界值测试：**

+ 最小边界：刚开始即提交（测试用例 Q04）
+ 最大边界：倒计时结束时提交（测试用例 Q05）
+ 超出边界：超时后继续答题（测试用例 Q06）

**答案长度边界值测试：**

+ 最小边界：空答案（测试用例 Q07）
+ 最大边界：最大允许字符数（测试用例 Q08）
+ 超出边界：超出字符上限（测试用例 Q09）

**提交操作边界测试：**

+ 单击提交（测试用例 Q10）
+ 连续多次点击提交（测试用例 Q11）

# **三、乱序答题模块测试用例说明**
## **（一）等价类划分法**
### **方法概述**
等价类划分是将输入域划分为若干个等价类，从每个等价类中选取少数代表性数据作为测试用例。

### **在乱序答题功能中的设计思路**
**核心设计理念：**

1. 根据乱序答题功能的业务规则，将每个功能的输入条件（如用户状态、题目状态、数量参数等）划分为有效等价类和无效等价类
2. 有效等价类代表符合业务规则的输入，应导致预期的成功行为（如正常显示题目、进度或提示信息）
3. 无效等价类代表违反业务规则的输入，应导致错误处理或适当提示（如重定向、错误信息）

**具体设计策略：**

1. **用户状态维度划分：**
    - 根据用户是否登录、是否有答题历史、是否有未答题目、是否有错题等条件，设计有效和无效等价类
    - 例如：用户已登录且存在未答题目（有效）、用户未登录（无效）
2. **题目状态维度划分：**
    - 根据题目是否存在、是否已完成、是否答错等条件，设计等价类
    - 例如：存在未答题目（有效）、所有题目已完成（有效）、无错题（无效）
3. **数量参数维度划分：**
    - 对于获取指定数量题目的功能，根据数量范围设计有效和无效等价类
    - 例如：数量在题库范围内（有效）、数量超过题库总数（无效）

**在本项目中的应用：**  
**随机题目获取测试：**

+ 有效等价类EC1：用户已登录且存在未答题目（T-RND-001，预期显示随机未答题目和进度）

### **在乱序答题功能中的设计思路**

    - 测试错题数量的边界（如0错题、1错题）
3. **路由访问边界测试：**
    - 测试在极端状态下访问路由的行为（如无历史时重置、无题目时获取）

+ 最大边界：数量为题库总数（应返回全部题目ID且不重复）
+ 超出边界：数量为0或题库总数+1（应返回空列表或错误提示）

**错题练习模式测试：**

+ 边界条件：无错题或未答题（T-RND-005，预期显示提示并重定向）

**答题进度显示测试：**

+ 边界条件：已答题数为0或总题数（进度格式应正确显示"已答0/总数Y"或"已答Y/总数Y"）

## **（一）等价类划分法**
### **方法概述**
等价类划分是将输入域划分为若干个等价类，从每个等价类中选取少数代表性数据作为测试用例。

### **在定时定量答题功能中的设计思路**
**核心设计理念：**

1. 根据定时定量答题功能的业务规则，将每个功能的输入条件划分为有效等价类和无效等价类
2. 有效等价类代表符合业务规则的输入，应该导致功能正常执行
3. 无效等价类代表违反业务规则的输入，应该导致错误处理或适当提示

**具体设计策略：**

    - 考虑参数缺失时的默认值处理
3. **时间状态维度划分：**
    - 根据定时模式时间是否到期设计等价类
    - 考虑时间边界的不同状态
4. **用户状态维度划分：**
    - 根据用户是否登录、是否有权限等条件设计等价类

**在本项目中的应用：**
